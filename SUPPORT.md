# Support

- **Questions and discussion:** [Discord](https://wilds.ai/discord). GitHub issues are for bugs and feature requests.
- **Documentation:** [docs.agentos.sh](https://docs.agentos.sh)
- **Bugs and feature requests:** the [issue forms](https://github.com/framerslab/agentos-skills-registry/issues/new/choose). Search the existing issues first. A problem with a skill's content belongs in [agentos-skills](https://github.com/framerslab/agentos-skills/issues), and a bug in the runtime belongs in [agentos](https://github.com/framerslab/agentos/issues/new/choose).
- **Security issues:** report privately as the [security policy](https://github.com/framerslab/agentos-skills-registry/blob/master/.github/SECURITY.md) describes, never in a public issue.
- **Commercial, partnership or sponsorship inquiries:** team@frame.dev

To contribute, see [CONTRIBUTING.md](https://github.com/framerslab/agentos-skills-registry/blob/master/CONTRIBUTING.md).
